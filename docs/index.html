FEATURES

REAL-TIME TRANSCRIPTION

Diarized speaker separation powered by Deepgram Nova-2. Captures every word with automatic speaker identification using channel-based audio routing.

HERMES INTELLIGENCE

Leverages Hermes Agent as the core reasoning engine. Processes meeting context in real-time to extract insights, decisions, and action items automatically.

SCREEN AWARENESS

Capture and analyze screen content during meetings. Vision model integration provides context-aware assistance for technical discussions and presentations.

OBSIDIAN INTEGRATION

Automatically saves structured meeting notes to your Obsidian vault. Includes summaries, action items, and full transcripts in markdown format.

CALENDAR SYNC

Connects with Google Calendar to track scheduled meetings. Automatically starts recording when meetings begin and adds context from calendar events.

REAL SANDBOXING

Five backends — local, Docker, SSH, Singularity, Modal — with container hardening and namespace isolation. All processing happens locally.
