THE AGENT THAT
GROWS WITH YOU.

Not a coding copilot tethered to an IDE or a chatbot wrapper around a single API. An autonomous agent that lives on your server, remembers what it learns, and gets more capable the longer it runs — now with meeting intelligence.

1. INSTALL
git clone https://github.com/EstebanCastel/cluely-hermes.git
2. CONFIGURE
cd cluely-hermes && npm install
3. CONNECT TO HERMES
echo setup --calendar google --transcripts enabled

CALENDAR INTEGRATION

Seamlessly connects with Google Calendar, Outlook, and CalDAV. Automatically detects meetings, joins at the right time, and captures everything without manual intervention.

REAL-TIME TRANSCRIPTION

Advanced speech-to-text engine that identifies speakers, handles crosstalk, and maintains context. Works with virtual and in-person meetings across all major platforms.

INTELLIGENT SUMMARIES

Powered by state-of-the-art LLMs to extract decisions, action items, and key discussions. Customizable formats from bullet points to detailed narratives.

HERMES MEMORY

Meeting context becomes part of Hermes Agent's long-term memory. Ask about past decisions, track action items across meetings, and maintain project continuity.

PRIVACY FIRST

All processing happens locally on your infrastructure. No cloud storage, no third-party access. You own your data, always. Enterprise-grade encryption throughout.

EXTENSIBLE PLATFORM

Built on Chrome Extension architecture with a powerful API. Create custom workflows, integrate with your tools, and extend functionality through the Hermes ecosystem.
