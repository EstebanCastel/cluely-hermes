Core Capabilities

Echo combines real-time transcription with Hermes AI to deliver comprehensive meeting intelligence

Live Transcription

Real-time diarized transcription powered by Deepgram. Separates speakers automatically using advanced channel separation through macOS audio architecture.

Hermes Intelligence

Leverages Hermes Agent as the core reasoning engine. Processes meeting context in real-time to extract insights, decisions, and action items automatically.

Screen Awareness

Capture and analyze screen content during meetings. Vision model integration provides context-aware assistance for technical discussions and presentations.

Obsidian Integration

Automatically saves structured meeting notes to your Obsidian vault. Includes summaries, action items, and full transcripts in markdown format.

Calendar Sync

Connects with Google Calendar to track scheduled meetings. Automatically starts recording when meetings begin and adds context from calendar events.

Privacy First

All processing happens locally on your machine. Content protection mode ensures privacy during screen sharing. Your data never leaves your control.

Hermes Integration

Echo connects to Hermes through a Python sidecar bridge, maintaining hot session state for real-time analysis. Meeting context flows through the agent pipeline to extract decisions, action items, and key insights automatically.
