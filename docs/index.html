FEATURES

HERMES AS ENGINE

Not a wrapper around a single LLM. Hermes Agent is the reasoning engine — with persistent memory, auto-generated skills, and cross-session context that grows the longer you use it.

Real-time speech-to-text captures everything said in the meeting. Transcripts are saved, indexed, and become part of Hermes's permanent knowledge base.

OBSIDIAN VAULT SYNC

Every transcript, summary, and action item flows into your Obsidian vault as linked markdown. Search across meetings. Build a knowledge graph of decisions.

STEALTH OVERLAY

Invisible to Zoom, Teams, Meet, and Discord screen sharing. Click-through transparency, process disguise, always-on-top floating window only you can see.

FULL CONTEXT ANSWERS

When you ask a question mid-meeting, Hermes answers with knowledge from all your previous meetings, not just the current one. Decisions, dates, owners — everything recalled.

CONNECT ECHO TO HERMES

1 INSTALL HERMES AGENT

If you have not installed Hermes yet, run the one-liner. Skip this if Hermes is already running.

# macOS / Linux
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

# Windows (PowerShell)
irm https://hermes-agent.nousresearch.com/install.ps1 | iex

# Then configure
hermes setup
2 INSTALL THE OBSIDIAN SKILL

Echo stores transcripts in your Obsidian vault. Hermes has a built-in Obsidian skill for reading, searching, and writing notes.

# Verify the skill is available
hermes skills list | grep obsidian

# Set your vault path
hermes config set obsidian.vault_path ~/Documents/MyVault
3 CONNECT GOOGLE CALENDAR

Echo reads your schedule via Google Workspace integration so Hermes knows your upcoming meetings, attendees, and agendas.

# Install gws CLI
pip install google-workspace-cli

# Authenticate
gws auth login
4 INSTALL ECHO

Clone the repo and run setup. Echo is an Electron app that creates the stealth overlay and manages audio capture.

git clone https://github.com/EstebanCastel/cluely-hermes.git
cd cluely-hermes
./setup.sh
5 CONFIGURE THE .ENV

Tell Echo where Hermes is running and which vault to use. The setup script creates this file from the template.

# .env
HERMES_HOST=localhost
HERMES_PORT=8080
OBSIDIAN_VAULT=~/Documents/MyVault
GCAL_ENABLED=true
SPEECH_PROVIDER=whisper
WHISPER_MODEL=base
6 START THE GATEWAY

Hermes gateway must be running so Echo can send queries. If already running (check with hermes status), skip this step.

# Check if gateway is running
hermes status | grep Gateway

# If not, start it
hermes gateway start

CONFIGURATION

VARIABLE STATUS DESCRIPTION
HERMES_HOST REQUIRED Hermes Agent gateway host. Default: localhost
HERMES_PORT REQUIRED Gateway port. Default: 8080
OBSIDIAN_VAULT REQUIRED Absolute path to your Obsidian vault where transcripts will be stored
GCAL_ENABLED OPTIONAL Enable Google Calendar integration. Requires gws CLI authentication
SPEECH_PROVIDER OPTIONAL whisper (local, offline) or azure (real-time cloud). Mic hidden if unset
WHISPER_MODEL OPTIONAL Local Whisper model size: tiny, base, small, medium, large
AZURE_SPEECH_KEY OPTIONAL Azure Cognitive Services key for real-time live transcription
AZURE_SPEECH_REGION OPTIONAL Azure region (e.g. eastus). Required when using Azure Speech
TRANSCRIPT_FORMAT OPTIONAL Obsidian note format: markdown (default) or timestamped
STEALTH_PROCESS_NAME OPTIONAL Process name disguise: Terminal, ActivityMonitor, Settings
