// Core Features

Engineering-First Meeting Intelligence

Built for developers who need more than just transcription

🎙️

Diarized Transcription

Real-time speaker separation using Deepgram's neural networks with channel-based diarization through macOS Aggregate Device architecture.

deepgram.listen.live({diarize: true})
🧠

Hermes AI Core

Leverages Hermes agent as the reasoning engine via Python sidecar bridge, providing contextual understanding and intelligent meeting insights.

hermes.AIAgent(session="hot")
👁️

Screen Context

Capture and analyze screen content with ⌘⇧S. Vision model processes screenshots for context-aware assistance during technical discussions.

capture.screenshot() → vision.analyze()
📝

Obsidian Vault

Automatic markdown note generation with structured meeting summaries, action items, and full diarized transcripts saved to your knowledge base.

vault.save("YYYY-MM-DD-Meeting.md")
📅

Calendar Sync

Google Calendar API integration for automatic meeting detection and contextual recording triggers based on scheduled events.

calendar.events.watch(trigger=True)
🔒

Privacy Shield

Content protection mode makes UI undetectable during screen sharing. All processing happens locally with optional encryption.

mode="stealth" encryption=AES-256

Intelligent Context Pipeline

Echo bridges multiple services through a unified Python sidecar that maintains hot session state with Hermes. Meeting context flows through the agent for real-time analysis and decision extraction.

from sidecar import HermesBridge
