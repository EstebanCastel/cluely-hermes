Quick Installation

Get Echo up and running in minutes

1

Prerequisites

Ensure you have the required dependencies installed on your macOS system.

🍎
macOS
Apple Silicon
🤖
Hermes
AI Agent
🎵
FFmpeg
Audio processing
🔊
BlackHole
Virtual audio
2

Install Hermes

Install the Hermes AI agent that powers Echo's intelligence.

# Install Hermes (if not already installed)
curl -fsSL https://raw.githubusercontent.com/nousresearch/hermes-agent/main/install.sh | bash

# Verify installation
hermes --version
3

Install Dependencies

Install required system dependencies and audio tools.

# Install FFmpeg
brew install ffmpeg

# Install BlackHole (download from website)
# https://github.com/ExistentialAudio/BlackHole

# Create Aggregate Device in Audio MIDI Setup:
# Name: "OpenCluely In"
# - Channel 0: Your Microphone
# - Channels 1-2: BlackHole 2ch
4

Clone and Setup Echo

Clone the repository and install Node.js dependencies.

# Clone the repository
git clone https://github.com/EstebanCastel/cluely-hermes.git
cd cluely-hermes

# Install dependencies
npm install

# Setup Deepgram API key
mkdir -p ~/.Echo
echo "DEEPGRAM_API_KEY=your_api_key_here" >> ~/.Echo/.env
5

Build and Install

Build the application and install it to your Applications folder.

# Create signing certificate (first time only)
npm run create-cert

# Build and install the app
npm run build-and-install

# Or run in development mode
npm start

Hermes Integration Guide

Connect Echo with Hermes for powerful AI capabilities

🔗 Configure Hermes as Provider

Echo uses Hermes as its AI brain through a Python sidecar bridge. This integration enables contextual understanding of your meetings and intelligent responses.

1

Configure Hermes Provider

Set up Hermes with your preferred LLM provider (OpenAI, Claude, etc.).

# Configure Hermes
hermes config

# Add your API keys
hermes config set openai.api_key YOUR_OPENAI_KEY
# OR
hermes config set anthropic.api_key YOUR_CLAUDE_KEY

# Set default model
hermes config set model gpt-4o  # or claude-3-opus
2

Configure Echo Settings

Update Echo's configuration to connect with your Hermes installation.

# Echo automatically finds Hermes at:
# ~/.hermes/hermes-agent/venv/bin/python3

# If using a custom Hermes location, update in Echo settings:
# Settings → AI → Hermes Path
3

Enable Meeting Context

Configure context persistence for meeting history across sessions.

# Create Hermes skill for meeting context
cat > ~/.hermes/skills/meeting-assistant.md << 'EOF'
---
name: meeting-assistant
description: Meeting context and history management
---

# Meeting Assistant Skill

When processing meeting transcripts:
1. Identify key topics and action items
2. Track speaker contributions
3. Generate concise summaries
4. Link to previous meeting context
5. Extract decisions and next steps
EOF

# Enable the skill
hermes skill enable meeting-assistant

📚 Obsidian Integration

Automatically save meeting notes and transcripts to your Obsidian vault.

1

Configure Obsidian Vault

Set the path to your Obsidian vault in Echo settings.

# Open Echo Settings (⌘,)
# Navigate to: Settings → Storage → Obsidian
# Set vault path: ~/Documents/ObsidianVault

# Or configure via environment
echo "OBSIDIAN_VAULT_PATH=~/Documents/ObsidianVault" >> ~/.Echo/.env
2

Meeting Notes Template

Echo automatically creates structured meeting notes.

# Notes are saved as:
# ObsidianVault/Meetings/YYYY-MM-DD-Meeting-Title.md

# Example structure:
---
date: 2024-01-15
participants: ["You", "Colleague"]
duration: 45min
tags: #meeting #project-alpha
---

## Summary
[AI-generated summary]

## Key Topics
- Topic 1
- Topic 2

## Action Items
- [ ] Action item 1
- [ ] Action item 2

## Transcript
[Full diarized transcript]

📅 Google Calendar Integration

Connect with Google Calendar to automatically track and record scheduled meetings.

1

Enable Google Calendar API

Set up Google Calendar API access for Echo.

# 1. Go to Google Cloud Console
# 2. Create new project or select existing
# 3. Enable Google Calendar API
# 4. Create credentials (OAuth 2.0 Client ID)
# 5. Download credentials.json

# Place in Echo config directory
mv ~/Downloads/credentials.json ~/.Echo/google-credentials.json
2

Authorize Echo

Grant Echo access to your calendar.

# Run Echo and navigate to Settings
# Settings → Integrations → Google Calendar
# Click "Connect Google Calendar"
# Follow OAuth flow in browser

# Echo will now:
# - Show upcoming meetings
# - Auto-start recording when meetings begin
# - Add meeting context to transcripts
